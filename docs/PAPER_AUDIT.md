# Manuscript consistency and provenance audit

These issues were found while connecting the submitted manuscript to saved
experiments. The manuscript itself was not edited or included in the release.
They are limitations of an exact-reproduction claim, not instructions to change
experimental observations.

## Direction-scale population

The manuscript's direction-scale appendix uses an older **649-unit** report.
The available complete C36 shards contain **661 common eligible units**. The
reproduction command reports the latter and records that population explicitly.
The identities of the 12 previously missing units were not recovered as a
complete frozen subset. The old four-row table therefore cannot be asserted to
be an exact reanalysis of the current complete artifacts. Use the regenerated
table/population consistently in the manuscript, or recover the original subset.

## Position-pair sampling

The shared component digest used by the latent and concept experiments is named
`...comp_s4.pt`: it was fitted with target-position stride **4**. Full = diagonal
+ off-diagonal remains exact on the sampled targets, but that does not establish
that every target position was enumerated. The release configuration records
stride 4; the paper should disclose the sampling convention. Stride 1 is a
separate, more expensive estimator and would be a new fit.

## Statistical units and intervals

Concept outcome rates average each unit's eligible relational queries first,
then average the 661 units. The 1,339-query count describes the underlying
queries, not a query-weighted outcome-rate estimator. Margin/gradient analyses
use query-level rows clustered by source entity.

The magnitude and gradient reports use **1,000** bootstrap draws (seed 0).
The scripted figure suite uses **10,000** (seed 160926); the latent paired report
uses 10,000 category-cluster draws (seed 42101). The original concept report uses
10,000 source-entity draws (seed 3201). A blanket claim that every interval uses
1,000 draws does not describe all these artifacts. Point estimates need not
change; Monte Carlo interval endpoints can.

## Figure provenance

The manuscript references an image called `fig_overview.png`. The available
final generator writes `01_overview` through `05_competition` and supporting
figures instead. No code that creates that separately composed PNG was located.
The release rebuilds the verified scripted suite; it does not claim pixel-exact
reproduction of an image with no identified generator. Use scripted assets, or
supply the source for the final composite.

## Historical environment and fitting data

The original GPU image installed dependency ranges and did not record a full
runtime lock/CUDA version. Immutable model revisions were recovered from the
local cache during cleanup, not from every historical remote payload. The
component fitting-text snapshot is available, but original dataset revisions
and text snapshots for every independent corpus replicate are not. Raw trial
outputs permit exact count reanalysis; fresh GPU and corpus-stream runs should
be described as reruns with their newly recorded environment.

## Interpretation boundaries

The latent panel includes pilot/development items; the concept panel was held
out from fitting but reused for follow-up analyses. Whole-prompt edits are
recomputed for each query; only prefix-only experiments support the literal
same-prefix-edit comparison. Corpus strengths were selected on evaluation
subsets. Do not merge these populations or describe these follow-ups as new
held-out confirmations. Filtering's benefit is placement- and dose-dependent.
